# Ecommerce Analytics Dashboard

## Project Overview
An interactive Power BI dashboard built to analyze ecommerce sales performance, customer behavior, product trends, and profitability.

## Dashboard Pages

### Home Page
Navigation hub for the dashboard.

### Executive Overview
- Total Sales
- Total Profit
- Total Orders
- Total Customers
- Profit Margin %

### Deep Sales Analysis
- Revenue Segmentation
- Revenue Trend & MoM Growth
- Product Performance Matrix
- Top Products Analysis
- Category Performance

## Tools Used
- Power BI
- DAX
- Power Query
- Excel/CSV

## Dataset
- fact_sales.csv
- dim_customers.csv
- dim_products.csv
- state_region_mapping.csv
